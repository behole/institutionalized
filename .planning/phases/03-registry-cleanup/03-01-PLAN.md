## Task 1: Create `core/registry.ts`

Create `core/registry.ts` exporting the canonical `FRAMEWORKS` record. This is the union of the CLI's rich metadata and the MCP's input schemas.

**Structure:**

```typescript
export interface FrameworkMetadata {
  // CLI fields (from cli.ts FRAMEWORKS)
  description: string;
  tier: string;
  category: string;
  purpose: string;
  agents: string[];
  agentCount: number;
  complexity: string;
  bestFor: string;
  exampleUseCases: string[];
  typicalTime: string;
  output: string;
  // MCP field
  inputSchema: Record<string, unknown>;
  // Directory mapping (from cli.ts FRAMEWORK_DIRS)
  dir: string;
}

export const FRAMEWORKS: Record<string, FrameworkMetadata> = {
  // ... all 26 frameworks, metadata from cli.ts, inputSchema from mcp-server/index.ts
};

export const FRAMEWORK_NAMES = Object.keys(FRAMEWORKS);
```

**Data sources:**

- Rich metadata (description, tier, category, purpose, agents, agentCount, complexity, bestFor, exampleUseCases, typicalTime, output): copy from `cli.ts` lines 43-544.
- `inputSchema`: copy from `mcp-server/index.ts` lines 13-356 for the 20 existing frameworks.
- `inputSchema` for the 6 missing frameworks (hegelian, talmudic, regulatory-impact, war-gaming, writers-workshop, dissertation-committee): create new schemas based on each framework's `types.ts` input interface. Each schema is a JSON Schema object with `type: object`, `properties`, and `required`.
- `dir`: copy from `cli.ts` `FRAMEWORK_DIRS` lines 551-577. For most frameworks, dir === name. This consolidates the separate mapping.

**Export from `core/index.ts`:** Add `export * from './registry';` to `core/index.ts`.

## Task 3: Wire `mcp-server/index.ts` to registry and fix args bug

1. Remove the inline `FRAMEWORKS` const (lines 13-356).
2. Add import: `import { FRAMEWORKS, FRAMEWORK_NAMES } from '../core/registry';`
3. Update `ListToolsRequestSchema` handler to iterate over `FRAMEWORK_NAMES` and build tool definitions from `FRAMEWORKS[name].description` and `FRAMEWORKS[name].inputSchema`. This automatically exposes all 26 frameworks (REG-02).
4. **Fix the args bug (PROV-04):** In the `CallToolRequestSchema` handler (line 399), change:
   ```typescript
   const result = await framework.run(args, args);
   ```
   to:
   ```typescript
   const input = args ?? {};
   const flags = { verbose: false };
   const result = await framework.run(input, flags);
   ```
   The first argument is the domain input (the MCP tool arguments). The second is a `RunFlags` object — MCP doesn't expose verbose/rounds as flags, so pass a minimal default. If MCP tool arguments include verbose, extract it into flags rather than passing in input.
